# 📱 Google Play Store Analysis

An end-to-end data analytics project focused on exploring Google Play Store applications to understand app popularity, user ratings, installations, pricing, and category-wise performance.

## 📊 Project Overview

Analyzed **10,841 app records** to identify patterns in app distribution, user preferences, ratings, and market performance through Python, Excel, and Power BI.

## 🔍 Key Analysis

- **Data Cleaning:** Removed duplicates, handled missing values, and transformed data types.
- **Category Analysis:** Explored app distribution and performance across categories.
- **Rating Analysis:** Examined rating distributions and category-wise ratings.
- **Installation Analysis:** Analyzed app popularity based on installation counts.
- **Free vs Paid:** Compared free and paid applications.
- **User Preferences:** Explored content ratings and app distribution.

## 🛠️ Tools & Technologies

- **Python:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Microsoft Excel:** Pivot Tables and Interactive Dashboard
- **Power BI:** Interactive Dashboard and Data Visualization
- **Google Colab:** Data Cleaning and Exploratory Data Analysis (EDA)

To transform raw Google Play Store data into meaningful insights that help understand app market trends, user preferences, and application performance.
